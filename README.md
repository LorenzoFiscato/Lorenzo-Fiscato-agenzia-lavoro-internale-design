# Agenzia di lavoro interinale - Design

Progettazione di un'applicazione web per l'assegnazione diretta a tempo determinato
dei clienti di un'agenzia di lavoro interinale alle aziende che ne fanno richiesta

## Utenti
- **Azienda**: si registra al servizio e inserisce le offerte di lavoro
- **Cliente**: persona in cerca di occupazione; si registra, elabora richieste di
  occupazione e visualizza i risultati

## Requisiti
- L'azienda può registrarsi
- L'azienda può inserire un'offerta di lavoro, specificando tipologia, titolo richiesto, data di inizio/fine e compenso orario
- Il cliente può registrarsi
- Il cliente può elaborare una richiesta di occupazione specificando tipologia, titoli posseduti, data di inizio/fine della disponibilità
- Il cliente può visualizzare l'elenco delle offerte compatibili con la sua richiesta

## Note
- Il server che memorizza offerte e richieste esiste già, quindi non è da progettare
